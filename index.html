Mojolinux Backup

Mojolinux Backup is a personal, privately operated backup application. It uses Restic and rclone to store encrypted backups of the operator's files in the operator's Google Drive account and to restore those backups.

The application requests Google Drive access to files it creates or uses, so it can maintain the encrypted backup repository. It is intended for the operator's personal use and is not offered as a public backup service.

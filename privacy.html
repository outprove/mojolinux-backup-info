Privacy notice

Mojolinux Backup is a personal backup application operated by its owner. It uses Restic and rclone to store and retrieve encrypted backups in the owner's Google Drive.

The app requests the Google Drive drive.file permission to create and manage files it uses. It uses that access to upload and retrieve encrypted repository objects and, when the operator manages backups, update or remove those objects. It does not request general access to all files in Google Drive.

Restic encrypts backup data before upload. Google Drive stores the encrypted repository objects and associated service metadata. The operator stores authorization and recovery credentials in protected files and keeps a separate recovery copy.

The operator does not sell Google user data or use it for advertising. Google processes the stored objects under its own policies.

The owner can revoke access in Google Account permissions. Revocation prevents new Drive backups and restores until access is authorized again; removing the stored backup is a separate action.

Contact the operator through the operator's GitHub profile.
